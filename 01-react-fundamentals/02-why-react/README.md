# 2️ Why React?
You might ask:
"I can already build applications using JavaScript. Why do I need React?"
Excellent question.
Imagine your restaurant application eventually has:
Navbar
Search
Restaurant List
Restaurant Card
Food Card
Cart
Order Summary
Login
Profile
Payment
Footer
With plain DOM manipulation, managing all those UI elements manually can become difficult.

With plain DOM manipulation, managing all those UI elements manually can become difficult.

React lets you break the application into reusable components.

App
│
├── Navbar
├── SearchBar
├── RestaurantList
│   ├── RestaurantCard
│   ├── RestaurantCard
│   └── RestaurantCard
├── Cart
└── Footer

Main advantages:
  React
  │
  ├── Component-based architecture
  ├── Reusable UI
  ├── Declarative UI
  ├── Efficient UI updates
  ├── Large ecosystem
  └── Works well with modern frontend tooling
